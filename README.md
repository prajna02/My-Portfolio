# Prajna K — Portfolio

Personal portfolio built with Vite, React, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Add your resume

Place the file at `public/resume.pdf`. The **Download Resume** links in the nav, hero, and contact sections already point to `/resume.pdf`.

## Add a photo

Save the image (for example `public/profile.jpg`) and set `photo` in `src/data/content.ts` to `/profile.jpg`.

## Deploy on Vercel

Import this repository in Vercel (framework preset: Vite). Output directory: `dist`.
